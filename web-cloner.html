วิธีใช้ Bookmarklet ดูดซอร์สเว็บที่ติดสิทธิ์ล็อกอิน (หรือติด Cloudflare)

ขั้นตอนที่ 1: ติดตั้ง Bookmarklet ครั้งเดียว

ลากปุ่ม "📌 ดึงซอร์สเข้า Web Cloner" ด้านบนขึ้นไปวางบนแถบ Bookmark Bar (กด Ctrl+Shift+B เพื่อเปิดแถบ) หรือกดปุ่ม คัดลอกโค้ด Bookmarklet แล้วสร้าง Bookmark ใหม่วางโค้ดในช่อง URL

ขั้นตอนที่ 2: คลิกขณะล็อกอินอยู่ในหน้าเว็บเป้าหมาย

เมื่อเข้าหน้าเว็บที่ต้องการ (เช่น ระบบสมาชิก, Dashboard, หน้าเว็บเรนเดอร์จาก React/Vue) ให้คลิก Bookmark ที่บันทึกไว้ ระบบจะดูด DOM จริง + CSS Rules + JS + รายการรูปภาพ แล้วเปิดกลับมาที่หน้านี้อัตโนมัติ
