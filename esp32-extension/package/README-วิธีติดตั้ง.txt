=================================================================
  วิธีติดตั้งส่วนเสริม ESP32 DHT11 MQTT Snippets & Helper สำหรับ VS Code
=================================================================

วิธีที่ 1: ติดตั้งอัตโนมัติในคลิกเดียว (แนะนำ)
-----------------------------------------------------------------
1. แตกไฟล์ ZIP ออกมาไว้ในโฟลเดอร์เดียวกัน
2. ดับเบิลคลิกที่ไฟล์ "Install-ESP32-VSCode.bat"
3. โปรแกรมจะติดตั้งส่วนเสริมเข้า VS Code และเปิดหน้าต่างโค้ด ESP32 DHT11 MQTT ขึ้นมาให้อัตโนมัติทันที!

วิธีที่ 2: ติดตั้งผ่านหน้าโปรแกรม VS Code ด้วยตัวเอง
-----------------------------------------------------------------
1. เปิดโปรแกรม VS Code
2. ไปที่แถบ Extensions (ไอคอนสี่เหลี่ยมด้านซ้าย หรือกด Ctrl+Shift+X)
3. คลิกปุ่มจุด 3 จุด (...) ที่มุมขวาบนของแถบ Extensions
4. เลือกเมนู "Install from VSIX..."
5. เลือกไฟล์ "esp32-dht-snippets-1.0.0.vsix" แล้วกด Install

=================================================================
  วิธีใช้งานหลังติดตั้งเสร็จ
=================================================================
- ทันทีที่ติดตั้งเสร็จ โค้ด ESP32 + WiFi + MQTT + DHT11 จะเด้งขึ้นมาในหน้าต่างใหม่ทันที
- กดปุ่ม "เด้งโค้ด ESP32 DHT" ที่แถบด้านล่างซ้ายของจอ VS Code ได้ทุกเมื่อ
- หรือพิมพ์คำย่อ esp32, esp32dht, หรือ dhtmqtt ในไฟล์ใดก็ได้แล้วกด Tab
- กดปุ่ม "เช็ค MQTT/Server" ที่แถบด้านล่างซ้ายเพื่อเช็คสถานะเซิร์ฟเวอร์ 192.168.11.180
